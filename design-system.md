# Design System — Quick Reference

## Typography

**Cormorant Garamond**

* `display` — Hero, duże statementy, mocne hasła
* `h1` — główny tytuł
* `h2` — główne tytuły sekcji, np. „Poznaj nasze wina”
* `h3` — tytuły kart i podsekcji, np. „Bursztyn”, „Historia winnicy”
* `h4` — mniejsze nagłówki, np. „Nasz sposób pracy”

**Manrope**

* `lead` — ważny tekst pod nagłówkiem, intro sekcji, opis Hero
* `body` — zwykłe akapity, opisy, storytelling
* `small` — informacje drugorzędne, pomocnicze teksty, np. „Darmowa dostawa od 300 zł”
* `caption` — metadata, daty, kategorie, roczniki, np. „2024 · BIAŁE · 750 ML”

**Komponenty mają własną typografię:**

* Button → 13px / 600
* Nav → zależnie od desktop/mobile
* Label → zależnie od kontekstu

## Colors

### Neutral

* `off-white` → główne tło
* `beige` → alternatywne tło sekcji
* `black` → główny tekst
* `black-muted` → tekst drugorzędny

### Brand

* `primary-600` → **Rubin / główny akcent**
* `secondary-600` → **Natural Green / akcent natury**

### Product

* `wine-*` → tylko konkretne wina / produkty

### Semantic

* `success` → sukces
* `error` → błąd
* `warning` → ostrzeżenie

---

## Simple rule

**Cormorant = brand & editorial**
**Manrope = content & UI**
**Rubin = brand accent**
**Green = nature accent**
**Gemstone = product accent**
**White / Beige = backgrounds**
**Black = text**
